
# 💰 Organizaê – Organizador Financeiro Pessoal

## 📌 Sobre o projeto

O Organizaê é uma aplicação web desenvolvida para auxiliar no controle e planejamento financeiro pessoal.

A plataforma permite registrar receitas e despesas, acompanhar o saldo disponível e visualizar as movimentações financeiras por meio de um dashboard interativo.

O projeto busca oferecer uma experiência simples, intuitiva e organizada, facilitando o acompanhamento da vida financeira dos usuários.

## 🎯 Objetivo

Desenvolver uma ferramenta digital que facilite a gestão financeira pessoal, proporcionando maior controle sobre receitas, despesas e hábitos de consumo.

## ⚙️ Funcionalidades

- Cadastro de receitas e despesas.
- Categorização das movimentações financeiras.
- Cálculo automático do saldo disponível.
- Dashboard com resumo financeiro.
- Histórico de movimentações.
- Filtro por tipo de movimentação.
- Exclusão de registros.
- Gráfico de receitas e despesas.
- Armazenamento de dados no navegador.

## 🚀 Como executar o projeto

1. Acesse o repositório no GitHub.
2. Faça o download dos arquivos ou clone o repositório.
3. Abra o arquivo `index.html` no navegador.
4. Comece a cadastrar suas movimentações financeiras.

Também é possível acessar a aplicação por meio do GitHub Pages, caso esteja publicado.

## 💾 Armazenamento de dados

O projeto utiliza o LocalStorage do navegador para armazenar as movimentações financeiras.

Os dados permanecem salvos no navegador utilizado, mesmo após fechar a página. Entretanto, não existe sincronização entre diferentes dispositivos.

## 🔄 Versionamento
